Unified Memory RNASeq: Build a GPU-accelerated RNA-seq analysis pipeline that uses unified memory to process large datasets without repeated CPU–GPU transfers.

- Implement memory-efficient read alignment, transcript quantification, and differential expression workflows.
- Automatically manage unified memory across preprocessing, computation, and result aggregation.
- Support common input formats such as FASTQ, BAM, and count matrices.
- Benchmark performance, scalability, and memory usage against CPU-only and conventional GPU pipelines.
- Provide reproducible command-line execution, logging, and quality-control reports.
