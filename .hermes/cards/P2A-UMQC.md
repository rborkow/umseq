# Card P2A-UMQC — absorb the single-threaded QC tools into the resident pass

## Why
Tier 2A (`bench/PHASE2-tier2a-throughput.md`): Qualimap rnaseq, RSeQC (bam_stat,
read_distribution, read_duplication, junction_annotation, junction_saturation,
infer_experiment, inner_distance) and dupRadar are **58% of all task-wall** at ~1.0× CPU
efficiency — ~58 min of one-core work per sample. Every one of them is a single pass over
the same coordinate-sorted BAM + GTF that `crates/umbam` already holds resident. Picard and
bedtools are already absorbed (6/6 byte-compat gates, ~60 s for a 54M-record BAM).

This card adds `umbam qc` outputs that are **numerically identical** to the tools' text
outputs where the tool's output is deterministic text, and documents divergence where it
isn't (PDFs, R-fitted curves). MultiQC consumes the text files; nf-core wires them by
filename. Read `crates/umbam/src/lib.rs` first — `Resident`, `RecordHeader`, the shared
name-grouping helper, `FeatureIndex`, `count_fragments`, `mark_duplicates` — and build on
those. The goldens live in `~/uni-rnaseq-data/tier0/qc/` (generated by
`scripts/make_tier0_qc.sh`; run it if the directory is missing — it needs the `rnaseq`
conda env: `source ~/miniconda3/etc/profile.d/conda.sh && conda activate rnaseq`).

## Outputs, in order of difficulty; stop and report after any that resists ~2 attempts

### 1. RSeQC `bam_stat` → `D/rseqc/bam_stat.txt`
Pure flag/mapq/CIGAR counts over all records (see the golden for exact lines and
formatting; "Optical/PCR duplicate" = 0x400 count, "Non primary hits" = 0x100, "mapq <
mapq_cut" uses `mapq_cut = 30`, "Splice reads" = CIGAR contains N, "Reads mapped in proper
pairs" = 0x2, "Proper-paired reads map to different chrom" = 0x2 && tid != mtid). Counts
are over **reads** (records) exactly as the golden. Byte-identical gate.

### 2. RSeQC `read_distribution` → `D/rseqc/read_distribution.txt`
Needs the GTF → BED12 conversion nf-core does (`gtf2bed`), then the ten groups (CDS, 5'UTR,
3'UTR exons, introns, TSS up 1/5/10 kb, TES down 1/5/10 kb). Semantics per RSeQC source
(`read_distribution.py`): every aligned block ("tag" = each M-run of a spliced read) is
assigned to the first group in that priority order whose interval set it overlaps;
`Total_bases` per group is the merged interval length. Only records with mapq ≥ 30 (this
script's default), not 0x4, not 0x100/0x800, not 0x200. Byte-identical gate — note the
column widths are fixed-format (`%-20s%-20d%-20d%-20.2f` style); match them.

### 3. RSeQC `read_duplication` → `D/rseqc/pos.DupRate.xls`, `seq.DupRate.xls`
Position-based: key = (tid, pos, strand) for mapped reads; histogram of occurrence →
number of unique keys with that occurrence. Sequence-based: key = read sequence bytes
(reverse-complemented for reverse-strand? — check the source: RSeQC uses the *stored* SEQ
as-is); same histogram. Both up to `--up-limit 500`. Byte-identical.

### 4. dupRadar `dupMatrix.txt` → `D/dupradar/dupMatrix.txt`
dupRadar runs featureCounts **four times** on the markdup BAM (multi-mapper on/off ×
duplicates included/excluded) with `-s 0` and its own settings (`-t exon -g gene_id`,
paired, `--countReadPairs`, `-M --fraction` for the "Multi" columns? — read the dupRadar R
source: `analyzeDuprates` → `getDupMatrix`; nf-core passes `stranded = 0, paired = TRUE,
threads = N`). Reuse `count_fragments` with flag filters; the four count columns
(`allCountsMulti, filteredCountsMulti, allCounts, filteredCounts`) must match; derived
columns (`dupRate*, RPK*, RPKM*`) are arithmetic on those + `geneLength` — match to R's
default `%.15g`-ish printing or document the float-format divergence in COMPAT.md and gate
on the four integer columns. The `intercept_slope.txt` file comes from an R GLM fit
(`duprateExpFit`) — **skip it**; note in COMPAT.md that MultiQC's dupRadar module reads
only `dupMatrix`/`_intercept_slope`, and the fit can be done downstream in R from our
matrix.

### 5. Qualimap `rnaseq_qc_results.txt` → `D/qualimap/rnaseq_qc_results.txt`
Reproduce the "Reads alignment", "Reads genomic origin", and "Transcript coverage profile"
sections' numbers (the golden shows the format). "aligned to genes / ambiguous / no
feature" use Qualimap's own union counting over *reads* not fragments with
`uniquely-mapped-reads` (NH==1); "exonic/intronic/intergenic" classify each read by its
first block's overlap. 5'/3' bias uses the top-1000 transcripts by coverage and 100-bp
windows — this is the one likely to need a COMPAT note; get the alignment counts exact
first, then the origin percentages, then bias. Qualimap's `coverage_profile_along_genes_*`
files are optional.

### 6. RSeQC `junction_annotation` / `junction_saturation` / `infer_experiment` /
`inner_distance`
Junctions: every N in a CIGAR → (tid, intron_start, intron_end); annotate against the
GTF's intron set (from consecutive exons of each transcript) as known / partial-novel /
novel; counts of *events* (per read) and *junctions* (unique). Output the `.log` text and
`.junction.bed`. Saturation: subsample the junction events at 5%…100% (RSeQC's fixed
seeds — check whether it uses `random.seed` deterministically; if not, gate on the 100%
column only and note it). `infer_experiment`: fraction of reads whose strand agrees with
the gene strand, sampled over the first 200k mapped reads (`-s 200000`); reproduce the
three lines. `inner_distance`: histogram of mate inner distances for proper pairs; the
`.txt` is per-read and huge — emit it and gate on `inner_distance_freq.txt` only.

## Structure
- New module(s) under `crates/umbam/src/qc/`; `umbam chain` grows a `--qc` flag that runs
  everything above after the existing stages, each as a parallel pass over the sorted
  order. Add a `timing.tsv` row per output.
- Tests: `crates/umbam/tests/tier0_qc.rs`, one `#[ignore]`-gated test per output, same
  one-line-diagnostic style as `tests/tier0.rs` (read it). Compare against
  `~/uni-rnaseq-data/tier0/qc/<tool>/…`.
- COMPAT.md gets a section per tool listing any accepted divergence with a concrete
  example. Goldens decide; do not adjust a comparison to make it pass.
- Rules: `cargo fmt`; `cargo clippy -p umbam --all-targets -- -D warnings`; `unsafe` only
  in `umem`; no `git commit`; don't touch `docs/ bench/ .hermes/ KANBAN.md crates/umem/`
  or the Spark. You *may* add to `scripts/make_tier0_qc.sh` if a golden is missing or was
  generated with wrong flags — say so.

Finish with: the per-output gate table, Tier 0 `timing.tsv` (release, `--threads 12`), and
COMPAT.md additions.
