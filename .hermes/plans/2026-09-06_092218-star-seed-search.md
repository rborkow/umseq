> **For Hermes:** Use the subagent-driven-development skill to implement this plan task-by-task. Follow the resource handoff below before dispatching workers or touching Spark. This document authorizes no execution by itself.

**Goal:** Determine whether STAR's actual seeding workload merits a unified-memory GPU harness, then advance only a source-pinned, oracle-equivalent search boundary to implementation.

**Architecture:** Keep this work in an isolated STAR research lane, outside the existing Rust BAM/QC crates. def summarize(rows):
    import math
    from statistics import median

    groups = {}
    for row in rows:
        variant = row['variant']
        if variant not in {'stock', 'before', 'after'}:
            raise ValueError('unknown variant')
        wall = float(row['wall_s'])
        if int(row['exit_code']) != 0 or not math.isfinite(wall) or wall <= 0:
            raise ValueError('failed or invalid measurement')
        group = groups.setdefault(int(row['repeat']), {})
        if variant in group:
            raise ValueError('duplicate measurement')
        group[variant] = wall
    if not groups:
        raise ValueError('no measurements')
    deltas, fractions, stock_times = [], [], []
    for group in groups.values():
        if set(group) != {'stock', 'before', 'after'}:
            raise ValueError('incomplete repeat')
        delta = group['after'] - group['before']
        fraction = delta / group['stock']
        if not 0 < fraction < 1:
            raise ValueError('ablation is inconclusive; inspect raw measurements')
        deltas.append(delta)
        fractions.append(fraction)
        stock_times.append(group['stock'])
    fraction = median(fractions)
    return {
        'classification': 'ablation_estimate_not_exact_share',
        'repeats': len(groups),
        'median_stock_s': median(stock_times),
        'median_seed_ablation_s': median(deltas),
        'seed_ablation_range_s': [min(deltas), max(deltas)],
        'median_seed_ablation_fraction': fraction,
        'estimated_star_speedup_if_seed_2x': 1 / (1 - fraction + fraction / 2),
    }
```

def parse_time(text):
    import math

    fields = text.strip().split('\t')
    if len(fields) != 3:
        raise ValueError('invalid GNU time output')
    wall, rss, code = float(fields[0]), int(fields[1]), int(fields[2])
    if not math.isfinite(wall) or wall <= 0 or rss <= 0 or code != 0:
        raise ValueError('failed or invalid process timing')
    return {'wall_s': wall, 'peak_rss_kib': rss, 'exit_code': code}
```

def run_one(binary, index, r1, r2, out, threads, pairs):
    import json
    import subprocess

    out = Path(out)
    out.mkdir(parents=True, exist_ok=False)
    argv = star_command(binary, index, r1, r2, out, threads, pairs)
    (out / 'command.json').write_text(json.dumps(argv, indent=2) + '\n')
    command = ['/usr/bin/time', '-f', '%e\t%M\t%x',
               '-o', str(out / 'time.tsv')] + argv
    with (out / 'stdout.log').open('w') as stdout, \
         (out / 'stderr.log').open('w') as stderr:
        result = subprocess.run(command, stdout=stdout, stderr=stderr, check=False)
    if result.returncode != 0:
        raise RuntimeError(f'STAR failed ({result.returncode}); inspect {out}')
    final_log = out / 'Log.final.out'
    if not final_log.is_file() or final_log.stat().st_size == 0:
        raise RuntimeError(f'STAR final log missing: {out}')
    return parse_time((out / 'time.tsv').read_text())


def main():
    import argparse
    import csv
    import json

    parser = argparse.ArgumentParser()
    parser.add_argument('--lab', type=Path, required=True)
    parser.add_argument('--index', type=Path, required=True)
    parser.add_argument('--r1', type=Path, required=True)
    parser.add_argument('--r2', type=Path, required=True)
    parser.add_argument('--out', type=Path, required=True)
    parser.add_argument('--threads', type=int, default=20)
    parser.add_argument('--pairs', type=int, default=5000000)
    parser.add_argument('--repeats', type=int, default=3)
    args = parser.parse_args()
    if args.repeats < 3:
        parser.error('at least three measured repeats are required')
    args.out.mkdir(parents=True, exist_ok=False)
    rows = []
    orders = [('stock', 'before', 'after'), ('after', 'stock', 'before'),
              ('before', 'after', 'stock')]
    with (args.out / 'raw.tsv').open('w', newline='') as stream:
        fields = ['repeat', 'variant', 'wall_s', 'peak_rss_kib', 'exit_code']
        writer = csv.DictWriter(stream, fieldnames=fields, delimiter='\t')
        writer.writeheader()
        stream.flush()
        # Excluded warm-up. This warms file cache; each process still loads its index.
        run_one(args.lab / 'stock/source/STAR', args.index, args.r1, args.r2,
                args.out / 'warmup', args.threads, args.pairs)

                stream.flush()
    summary = summarize(rows)
    (args.out / 'summary.json').write_text(json.dumps(summary, indent=2) + '\n')
    print(json.dumps(summary, indent=2))


if __name__ == '__main__':
    main()

### Task 9 — freeze the semantic contract (2–5 minutes per source group)

Create `experiments/star-seed/CONTRACT.md`. It must contain the following exact decisions, with the source citations in section 1 verified against the pinned source:

1. **Two distinct scopes:** inner `maxMappableLength` requests versus complete `maxMappableLength2strands`/`storeAligns` seeding. A replay of the inner function is not the whole seed stage.
2. **Inner request fields:** format version; stable request ID; index identity; complete numeric `s[0]` and `s[1]` buffers needed by the call; `S`, `N`, `i1`, `i2`, `dirR`, and **incoming** `L`. Use explicit little-endian fixed-width integers in a future binary trace, never native struct dumps.
3. **Inner result:** final `L`, inclusive low/high SA endpoints, and returned mapping count. Compare every field per request, not an aggregate checksum alone.
4. **Full-seed result:** ordered emitted `storeAligns` arguments for every winning sparse offset, plus `maxLbest` and actual returned `Nrep`. Preserve input read/piece/start/direction ordering independently of GPU scheduling.
5. **Index state:** pin the actual loaded genome/SA/SAindex and parameters. Initial run is one-pass, fixed index, no insertion flags. Two-pass insertion creates a different in-memory index; do not replay its trace against original on-disk arrays.
6. **Packed access:** record `wordLength`, entry count, byte length, strand bit/mask, prefix-index offsets and marker masks. Retain packed storage and loader-required sentinels/padding. GPU loads must not assume host unaligned `uint*` dereferences are portable or safe.
7. **Input domain:** A/C/G/T numerical encoding, N and separator behavior must be traced from read loading and `qualitySplit`, not inferred from ASCII FASTQ. No blanket `3-base` complement for all possible symbols.
8. **Batching:** independent across ready reads/requests; adaptive scheduling within each read remains dependent. Trace replay measures available parallelism, not the overhead of producing it live.
9. **Unsupported cases:** a future experimental path must explicitly reject or CPU-route unsupported sparse indexes, insertion/two-pass states, or read modes, and report fallback counts. No silent approximation.
10. **Test matrix:** forward/reverse read direction × both genome strands; unique/repeated hits; single-entry interval; nonzero prefix `L`; short prefix; absent/N-marked prefix; chromosome/spacer boundary; sparseD=1 and a separately supported sparseD=3 path; no-good-piece reads; more than one seed per read; splice-junction sequence; long repetitive ranges.

## 5. Risks, tradeoffs, and open questions

1. **A random-gather microbenchmark is not a suffix search.** Prefix shortcuts, dependent traversal, long exact-match comparisons and divergent repeat lengths may erase the presumed structural advantage.
2. **The attractive hot loop may not dominate seeding.** Unique-hit extension bypasses the full binary-search routine; only profiling can choose the right boundary.
3. **Ablation is not exact attribution.** OFF switches alter downstream state. We preserve both sampling and differential evidence rather than laundering a subtraction into a precise fraction.
4. **Trace replay can overstate realizable batching.** Live STAR advances seeds based on earlier results. Integration may need queues across many reads, with a real latency/memory cost.
5. **Whole-index footprint matters.** Packed SA already occupies tens of GB; expanding it, keeping multiple indexes, or overlapping a BAM chain can exceed safe memory. Never use the nominal 128-GB label as available budget.
6. **Two-pass alignment is a different index state.** Initial scope excludes it explicitly, not accidentally. A fixed-index win cannot yet replace nf-core STAR.
7. **Source/license provenance.** Preserve STAR's license for any retained source; review redistribution obligations before vendoring or shipping a linked library. Do not claim legal compatibility without that review.
8. **Existing documents are stale in places.** The old 10% STAR fraction describes the old pipeline. The other lane's QC changes move the optimization target; obtain a new end-to-end baseline before cost claims.
9. **Coordination is not complete merely because this plan exists.** The other session has not acknowledged a lock protocol or yielded Spark in this turn. Execution is blocked on that handoff, not on more GPU availability checks.
10. **Shipping threshold versus research threshold.** The proposed 10% STAR-stage opportunity is a triage policy; the user may choose a different research budget. A scientifically useful negative result closes triage, not the original harness or integration card.
